A single Claude session in the compiler project starts when the system spins up a new container and runs a loop that keeps launching Claude with the same prompt, after setting up a git repo and logging. Inside that VM is a fresh copy of the shared codebase along with tests, scripts, and some instructions to help Claude understand what’s going on, while the main repo is used to coordinate between all the agents. When Claude starts, it reads the prompt, looks through the code, and picks a task by creating a lock file so other agents don’t work on the same thing, then it gets to work. It doesn’t just write code, it also reads docs, updates progress notes, runs tests, checks errors, and figures out what to do next. While working, it keeps building and testing the code, looking at short outputs and logs to debug issues, and sometimes writes down what didn’t work or breaks the problem into smaller pieces. Before finishing, it pulls in any new changes from other agents, merges conflicts if needed, pushes its updates back to the main repo, and removes its task lock. Then the session ends and a new one starts right away in a fresh container, repeating the same cycle of picking tasks, testing, fixing, and improving the project over time.
