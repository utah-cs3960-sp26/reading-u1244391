Autoresearch works best when a problem has a clear goal that can be measured, a fast way to test changes, and a limited space of possible solutions to explore. In these cases the system can repeatedly make small modifications, run experiments, and use the results to decide what to keep or discard based on a consistent metric. It is especially effective when improvement can be detected quickly from each trial so the process becomes a loop of trying ideas and refining them over time. This makes it well suited for tasks like model or system optimization where performance is directly measurable and each experiment is independent. On the other hand autoresearch does not work well when the problem is vague, subjective, or does not have a clear way to measure success. If there is no reliable signal to tell whether one attempt is better than another then the system cannot meaningfully learn from experimentation. It also struggles when the problem is too broad or requires long term reasoning or real world understanding that cannot be captured in a short evaluation cycle. Problems like trying to achieve something abstract such as world peace are unsuitable because there is no single objective function to optimize and no clear feedback loop to guide progress.
