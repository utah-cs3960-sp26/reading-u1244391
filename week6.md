Selecting is the technique used to add information to the context window and Compressing is the way you remove unnecessary tokens. Writing and Compressing are generally agent directed, whereas Selecting  is human authored. A clear example of an actual artifact you'd use is a CLAUDE.md file. this is a humanaauthored markdown file you check into your Git repository to provide the agent with specific project guidelines it can "select" and follow automatically.

In a memory unsafe language like C or C++, a fuzzer might uncover a use after free bug, where the system attempts to access a memory address that has already been deallocated. A class of vulnerability that Rust’s borrow checker prevents by design. In a memory safe language like Rust, a fuzzer is used to detect integer overflows or logic driven panics (such as those found in PNG decoders or malformed UTF-8 handling), which represent algorithm flaws and resource exhaustion that the type system alone cannot catch.
